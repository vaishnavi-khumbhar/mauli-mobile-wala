# Mauli Mobile Wala — Website

React + Vite + Tailwind + Framer Motion. Same layout system as the Aadarsh Awning site, recoloured to the Mauli logo (pink #EE1450 + black).

## Run
npm install
npm run dev      # http://localhost:5173
npm run build    # production files in /dist (includes .htaccess)

## Images
Put photos in `src/assets/images/` with these exact names (jpg/png/webp):
home-hero-1, home-hero-2, home-hero-3, hero-corner, brand-story,
product-apple, product-samsung, product-vivo, product-more-brands, product-accessories, product-electronics,
about-hero, store-interior, about-detail, products-hero, stores-hero, contact-hero,
store-1, store-2, store-3, store-4, cta-banner

## Content
- Phone, stores, hero text, why-us points: `src/data/site.js`
- Product categories: `src/data/products.js`
